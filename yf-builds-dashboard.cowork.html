Adding a build

Publishing happens in Claude Code. Everything else happens here.

“log this build” — said in Claude Code

It creates the GitHub repo, pushes the files, and registers the build. It will ask what to call it and which client it’s for if that isn’t obvious from what you were working on.

Why Claude Code and not here? Cowork can read GitHub but cannot push to it — that’s a hard limit of its sandbox, not a setting anyone can change. Claude Code runs on your own machine with your own GitHub login, so it can.

Get the skill. Ask ZF for yf-builds-publish. Once installed, the sentence above is genuinely all you need — no git commands, no repo settings.

Updating something that already exists — identical. Say the same thing; it spots the build is already published and adds a new version. Every previous version stays recoverable.

Download latest gives you a zip of the newest version, with no GitHub account needed — so it works for anyone you send it to.

Nothing secret in a build. Builds are public, which is what makes that download work. No API keys, no client data, no credentials.

A new build appears here after the next morning sync, or right away if you say “sync the builds” in Cowork. The commit line on each card is filled in by that same sync.

Add build registers a card by hand without publishing anything — useful for something hosted elsewhere. Most people should ignore it.
